70迈视频提取 APP —— 编译与使用说明
========================================

一、这是什么
-----------
一个 Android APP，专门解决"ES 文件管理器下载 70迈后视镜视频太麻烦"的问题。
功能：扫描后视镜 FTP 地址 → 连接 → 列出视频 → 勾选 → 一键批量下载到手机「下载」目录。
支持断点续传、后台下载、进度通知、历史地址。

前提：后视镜 FTP 服务可用（你现在用 ES 能下载，说明已满足）。
连接方式：手机开热点让后视镜连入，或后视镜开热点手机连入 —— 哪种能通就用哪种。


二、编译方式 A：GitHub 云编译（已完成，APK 已生成）
----------------------------------------------------------
代码已推送到 https://github.com/slayercjc/70mai.git ，云端编译已成功，
APK（2.98 MB）就在 GitHub 上，直接下载即可：

1. 打开 https://github.com/slayercjc/70mai/actions/runs/45927137776
   （或进仓库点 "Actions" → 点最上面那条绿色的运行记录 #7）
2. 页面拉到底 "Artifacts" → 点 "70mai-video-grabber-debug-apk" 下载（是个 zip）
   —— 需登录 GitHub 才能下载
3. 解压得到 app-debug.apk，传到手机安装（安装时允许「未知来源」）

以后改了代码，只要 git push，Actions 会自动重新编译出新 APK。
旧 APK（artifact）保留 30 天，过期就重新跑一次：
仓库 Actions 页 → 左侧 "Build Android APK" → "Run workflow" → 绿色按钮确认。


三、编译方式 B：本机 Android Studio
-----------------------------------
1. 打开 Android Studio → File → Open → 选择本文件夹（70mai-video-grabber）
2. 首次打开会提示 "Gradle JDK"——选 JDK 17（本机已装 Temurin 17）
3. 等待 Gradle Sync 完成（首次会联网下载依赖，需几分钟）
4. 手机开启「开发者选项」+「USB 调试」，用数据线连电脑
5. 顶部菜单 Run ▶ 选择你的手机 → 点运行，APP 自动安装
   或者：Build → Build Bundle(s)/APK(s) → Build APK(s)，
        生成的 APK 在 app/build/outputs/apk/debug/app-debug.apk，传到手机安装


四、如果 Gradle Sync 报错
-------------------------
- 报 "SDK not found"：Android Studio → Tools → SDK Manager → 安装 Android SDK Platform 34
- 报网络超时：File → Settings → Gradle → Gradle JDK 选 17；
  gradle.properties 里可加代理（如果你用代理上网）
- 报 JDK 版本：确认 Gradle JDK = 17（本工程用 AGP 8.5.2，要求 JDK 17）


五、使用方法
------------
1. 让手机和后视镜处于同一网络：
   推荐——手机开热点，后视镜 WiFi 连上这个热点（你已验证这条路 ES 能下载）
2. 打开 APP
3. 点「扫描网段」→ 自动找出后视镜 IP（通常 192.168.43.x）
   如果扫不到：打开 ES 文件管理器看它连的后视镜 IP，手动填进去
4. 点「连接并列出视频」
5. 进入文件夹找到录像；或点「扫描全部视频」一次性列出所有录像
6. 勾选要下载的视频 → 点「下载选中」
7. 后台下载，通知栏看进度；文件存到：手机存储/下载/70迈录像/日期/


六、常见问题
------------
Q：连接失败？
A：① IP 填错——用 ES 里那个 IP；② 端口 21；③ 账号保持匿名（anonymous / anonymous@）；
   ④ 后视镜 FTP 服务要开着；⑤ 手机和后视镜必须同网段。

Q：扫描不到设备？
A：手机必须连着 WiFi 或自身开热点；如果都扫不到就手动填 IP。
   注意：后视镜 FTP 是固件内置服务，无需在后视镜装 APP、也没有开关；
   ES 能连上就说明 FTP 在正常跑。手动填 IP 的方法：
   - 手机开热点、后视镜连入时：设置 → 个人热点 → 已连接设备，查看后视镜当前 IP
   - 后视镜开热点、手机连入时：就是网关 192.168.43.1 所在网段
   后视镜每次连热点拿到的 IP 可能变化，ES 里的旧地址只能当参考，以当前查到的为准。

Q：下载中断了？
A：重新连上后，再次勾选同一个文件下载，会自动从断点续传。

Q：下载的文件在哪？
A：文件管理器的「下载」目录 → 70迈录像 → 日期文件夹。或者用「我的文件」搜 mp4。


七、技术说明（供参考）
----------------------
- FTP 协议，Apache Commons Net 库，被动模式（PASV）
- 网段扫描：对当前 WiFi 网段 1-254 的 21 端口并发探测
- 下载：MediaStore（Android 10+）/ 公共目录（低版本），支持 REST 断点续传
- Kotlin + coroutines + AppCompat，minSdk 24，targetSdk 34
