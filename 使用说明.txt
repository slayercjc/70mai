70迈录像提取方案 —— 编译与使用说明
========================================

一、这是什么
-----------
本仓库产出两个 APK，配合解决"ES 文件管理器下载 70迈后视镜视频太麻烦"的问题：

  【后视镜端】70mai-mirror-ftpserver-apk（789 KB）
      装到后视镜里，开机自动在 3721 端口开启 FTP 服务，
      完全替代 ES 的「PC 网络功能」——以后不用每次在后视镜上手动开 FTP。

  【手机端】70mai-video-grabber-debug-apk（2.99 MB）
      装到手机里，扫描后视镜 IP → 连接 → 列出视频 → 勾选 → 批量下载。
      支持断点续传、后台下载、进度通知、历史地址。

连接方式：手机开热点，后视镜 WiFi 连入（你已验证这条路能通）。
地址多为 10. 开头，端口 3721。


二、APK 下载（GitHub 云编译已完成）
-----------------------------------
代码已推送到 https://github.com/slayercjc/70mai.git ，云端编译已成功。
打开这次运行：https://github.com/slayercjc/70mai/actions/runs/45987088121
（或进仓库点 "Actions" → 最上面那条绿色记录 #14）

页面拉到底 "Artifacts"，有两个 zip，分别下载：
  1. 70mai-mirror-ftpserver-apk  → 解压得 ftpserver-debug.apk（装后视镜）
  2. 70mai-video-grabber-debug-apk → 解压得 app-debug.apk（装手机）
—— 需登录 GitHub 才能下载。

以后改了代码只要 git push，Actions 自动重编译；artifact 保留 30 天。
过期就：仓库 Actions 页 → 左侧 "Build Android APK" → "Run workflow" → 绿色按钮。


三、后视镜端安装（关键步骤）
----------------------------
3.1 先确认系统版本
    后视镜 → 设置 → 关于本机 / 系统信息，查看 Android 版本。
    本 APP 要求 Android 4.4（API 19）及以上——绝大多数同期后视镜满足。
    若显示 4.0~4.3，请告知，需调整编译配置后重编。

3.2 安装 APK 到后视镜（按可行性排序）
    方法 A：ADB 安装（最稳）
      电脑装 PlatformIO/ADB → 后视镜开启「USB 调试」（设置→开发者选项，
      连点版本号 7 次可开启）→ USB 连电脑 → 执行：
        adb install ftpserver-debug.apk

    方法 B：U 盘 / 文件管理器
      把 ftpserver-debug.apk 拷进 U 盘 → 插后视镜 → 用后视镜自带文件管理器
      找到 APK 点击安装。若提示"禁止安装未知来源"，到 设置→安全 里开启。

    方法 C：系统"备份与还原 / 应用安装"
      部分 70迈系统自带的工具里有"安装本地应用"，选 APK 即可。

3.3 首次启动与自启设置
    装好后打开一次 APP（这一步不能省，否则系统不会注册开机广播）：
      - 界面会显示本机 IP、端口 3721、服务状态
      - 若显示"未运行"，点【启动 FTP 服务】
    然后到系统设置里，找到本 APP（名称"70迈FTP服务"），
    允许「自启动 / 后台运行 / 关联启动」——不同系统叫法不同，尽量都打开。
    这样后视镜重启后 FTP 会自动开。

3.4 验证后视镜端 OK
    手机开热点 → 后视镜连上 → 手机浏览器打开：
      ftp://后视镜IP:3721
    能弹出登录框（账号密码随便填或匿名）即表示服务正常。


四、使用方法（装了后视镜端 FTP 之后）
------------------------------------
1. 手机开热点，后视镜 WiFi 连上这个热点
2. 后视镜端 FTP 服务应已自动运行（第 3.3 步配置过）；
   若没自动开，在后视镜上打开"70迈FTP服务"APP 点【启动】
3. 手机打开"视频提取"APP
4. 点「扫描网段」→ 自动扫描所有候选网段（含 10.x），探测 3721/2121/21 端口，
   并自动填入发现的 IP 和端口
   如果扫不到：在后视镜 FTP APP 界面能看到本机 IP，手动填进去
5. 点「连接并列出视频」
6. 进入文件夹找到录像；或点「扫描全部视频」一次性列出所有录像
7. 勾选要下载的视频 → 点「下载选中」
8. 后台下载，通知栏看进度；文件存到：手机存储/下载/70迈录像/日期/

【备选路线】如果暂时没装后视镜端 FTP：
    每次要先在后视镜的 ES 文件管理器 → 「PC 网络功能 / 远程管理」→
    开启 FTP（老版 ES 端口 3721，地址多为 10. 开头），然后手机端照常操作。
    这就是以前的方式，能用，但每次都要手动开一步。


五、本机 Android Studio 编译（可选）
-----------------------------------
1. 打开 Android Studio → File → Open → 选择本文件夹（70mai-video-grabber）
2. 提示 "Gradle JDK" 时选 JDK 17
3. 等 Gradle Sync 完成（首次联网下载依赖，几分钟）
4. 编译两个 APK：
   手机端：app/build/outputs/apk/debug/app-debug.apk
   后视镜端：ftpserver/build/outputs/apk/debug/ftpserver-debug.apk
   或手机连数据线开 USB 调试，顶部 Run ▶ 选择安装到手机。

编译报错排查：
- "SDK not found"：SDK Manager 装 Android SDK Platform 34
- 网络超时：Gradle JDK 选 17；gradle.properties 可加代理
- JDK 版本：确认 Gradle JDK = 17（AGP 8.5.2 要求）


六、常见问题
------------
Q：后视镜装不上 APK？
A：① 先确认 Android ≥ 4.4；② 开启"未知来源"安装；③ 优先用 ADB 安装（第 3.2 步方法 A）；
   ④ 部分后视镜限制了安装来源，若三种方法都失败，说明系统锁死，只能继续用 ES 路线。

Q：后视镜重启后 FTP 没自动开？
A：① 装完必须手动打开过一次 APP（注册广播）；② 系统设置里允许本 APP 自启动/后台运行；
   ③ 有些定制系统会清理自启权限，系统升级后需重新检查；
   ④ 兜底：手动打开 APP 点【启动 FTP 服务】。

Q：连接失败？
A：① 后视镜 FTP 服务没启动；② IP 填错——用后视镜 FTP APP 显示的那个 IP；
   ③ 端口 3721；④ 账号保持匿名（anonymous / anonymous@）；
   ⑤ 手机和后视镜必须同网段。

Q：扫描不到设备？
A：先确认后视镜 FTP APP 显示"运行中"，再确认手机开了热点且后视镜已连入。
   都扫不到就手动填 IP+端口。后视镜每次连热点 IP 可能变化，以当前显示的为准。

Q：下载中断了？
A：重新连上后再次勾选同一个文件下载，会自动从断点续传。

Q：下载的文件在哪？
A：手机「下载」目录 → 70迈录像 → 日期文件夹。


七、技术说明（供参考）
----------------------
【手机端】
- FTP 协议，Apache Commons Net 库，被动模式（PASV）
- 网段扫描：所有候选网段（WiFi STA + 手机热点 10.x）1-254 的 3721/2121/21 三端口并发探测
- 下载：MediaStore（Android 10+）/ 公共目录（低版本），支持 REST 断点续传
- Kotlin + coroutines + AppCompat，minSdk 24，targetSdk 34

【后视镜端】
- 自研精简 FTP Server，仅依赖 java.net/java.io，无第三方库，APK 仅 789 KB
- 支持命令：USER PASS SYST FEAT OPTS TYPE PWD CWD CDUP PASV EPSV LIST NLST RETR REST SIZE MDTM NOOP QUIT
- 主动/被动模式均可用；手机端用 PASV
- 开机自启（BOOT_COMPLETED）+ 网络恢复触发 + 前台服务保活 + START_STICKY
- 路径安全：限制在外部存储根目录内，阻止 ../ 越界
- minSdk 19（Android 4.4）+，targetSdk 28；不用 AndroidX/协程/java.time，兼容老系统
- 界面纯代码构建，显示本机 IP 与服务状态，可手动启动/停止
